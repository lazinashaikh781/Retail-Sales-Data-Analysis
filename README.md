# Retail Sales Data Analysis Project

## Overview

This project analyzes a real-world retail sales dataset using Python. The goal is to extract meaningful business insights from customer transactions through data cleaning, exploratory data analysis (EDA), and data visualization.

The dataset contains transaction details such as customer demographics, product categories, quantities purchased, unit prices, and total sales amounts.

---

## Objectives

* Analyze retail sales performance
* Understand customer purchasing behavior
* Identify top-performing product categories
* Visualize sales trends and patterns
* Generate actionable business insights

---

## Dataset Information

The dataset contains the following fields:

| Column           | Description                   |
| ---------------- | ----------------------------- |
| Transaction ID   | Unique transaction identifier |
| Date             | Date of purchase              |
| Customer ID      | Customer identifier           |
| Gender           | Customer gender               |
| Age              | Customer age                  |
| Product Category | Category of purchased product |
| Quantity         | Number of items purchased     |
| Price per Unit   | Price of each item            |
| Total Amount     | Total transaction value       |
